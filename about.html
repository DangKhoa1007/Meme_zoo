About This Zoo

This page uses Flexbox to line up three unhinged creatures in a row, and they politely wrap onto new lines on small screens. The odd ones are circles because they are full of chaos, and the even one has cut corners because the nth-child selector said so.

How This Chaos Was Built

A skip link that hides until you press Tab (it uses :focus, so it is shy), a flex navigation bar, a CSS Grid hall of weirdos, hover transitions that make everything wiggle, and a proper box model on every image so none of them escape.
